# API REST de Authors, Posts y Comments

Repositorio de entrega del proyecto académico desarrollado con Node.js, Express y PostgreSQL.

## Organización del entregable

```text
.
├── Desarrollo/      # Código, SQL, tests, OpenAPI y configuración de Railway
├── Documentacion/   # Guía completa y registro del uso de IA
└── README.md        # Portada del repositorio
```

- [Código y ejecución](Desarrollo/README.md)
- [Documentación de entrega](Documentacion/README.md)
- [Especificación OpenAPI](Desarrollo/openapi/openapi.yaml)

La aplicación incluye CRUD de authors y posts, validaciones, consultas SQL parametrizadas, pruebas automatizadas y la entidad `comments` como extra credit.
